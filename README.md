# Portfolio

Modern portfolio built with Next.js + TypeScript.

## Features

- Hero section with clear call-to-action
- Dark and light mode toggle persisted in local storage
- Projects showcase with hover animations
- GitHub API integration to auto-load latest repositories
- About section with timeline and skill badges
- Contact form ready for Formspree
- Smooth page transitions using Framer Motion
- Responsive layout for mobile and desktop

## Setup

1. Install dependencies:
   - `npm install`
2. Configure environment:
   - Copy `.env.example` to `.env.local`
   - Set `NEXT_PUBLIC_GITHUB_USERNAME`
   - Set `NEXT_PUBLIC_FORMSPREE_ENDPOINT`
3. Start development:
   - `npm run dev`
