# Belay Kassanew | Portfolio

A responsive, accessible static portfolio for Belay Kassanew, a Computer Science and Public Health student, educator, and researcher focused on digital health, AI, and health technology.

## Structure

- `index.html` contains the semantic page content, initiatives, education, credentials, and social links.
- `styles.css` contains the responsive visual system and reduced-motion support.
- `script.js` contains the mobile navigation and lightweight scroll reveal behavior.
- `assets/profile.jpg` is the profile portrait used in the hero section.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server. No build step or dependency installation is required.

## Before publishing

Replace the placeholder email address in `index.html` with a professional address. Add verified project details as they become available; the current page intentionally does not invent projects, qualifications, or achievements.
