# Belay Kassanew | Portfolio

A responsive, accessible static portfolio for Belay Kassanew, focused on the intersection of software development, data analysis, public health, and health technology.

## Structure

- `index.html` contains the semantic page content and portfolio sections.
- `styles.css` contains the responsive visual system and reduced-motion support.
- `script.js` contains the mobile navigation and lightweight scroll reveal behavior.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server. No build step or dependency installation is required.

## Before publishing

Replace the placeholder email address in `index.html` with a professional address. Add verified project details and profile links as they become available; the current page intentionally does not invent projects, qualifications, or achievements.
